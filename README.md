# NoAbuse Hardcore — черновик (Minecraft 1.20.1, Fabric)

Первый draft из всего, что обсуждали. Сборка не проверена — соберёшь у себя и
пришлёшь, что вылезет.

## Что уже есть

1. **Тотем без мгновенных баффов** (`TotemMixin`) — спасает от смерти как
   обычно, но не даёт Regeneration/Absorption/Fire Resistance. Вместо этого:
   Голод 30 сек, Тошнота 15 сек, сытость сброшена в 0.
   *Не реализовано*: то, что еда какое-то время после этого восстанавливает
   меньше сытости/голода — этого в миксине пока нет, только сам факт голода.
2. **Око эндера всегда бьётся при поиске крепости** (`EyeOfEnderMixin`) —
   вместо ванильных 20%. На портал это не влияет.

## Чего пока нет (следующие шаги)

Голем, пиглины (броня/бартер), MLG-отключение, баг с релогом и
фолл-дэмаджем. Эндермены (лодка/проём) — в процессе, лог-дебаг не
завершён. Щит, лимит спавнеров — сделаны (см. `ShieldDamageMixin`,
`SpawnerLimitMixin`). Это всё либо сложнее (лезет в AI/Goal-классы), либо
требует уточнения деталей баланса.

## Идеи на будущее (записано, не реализовано)

### Фиксы эксплойтов мобов/боссов
- **Дракон Края + взрывы**: иммунитет дракона к урону от кроватей/якорей
  возрождения, либо полный запрет их установки в Энде.
- **Ворден vs "снайперы"**: если игрок отстреливает Вордена со столба —
  тот либо притягивает игрока звуковой волной, либо разрушает блоки под
  ним.
- **Иссушитель в бедроке**: если зажат в бедроке (потолок Ада / под
  порталом Края) — мгновенная телепортация на ближайшее свободное место.

### Фиксы абузов предметов/механик
- **X-Ray через композитор/поршень**: голова игрока внутри неполного/
  прозрачного блока → эффект Слепота.
- **Плод Хоруса / Элитры**: плод Хоруса не сбрасывает падение-урон после
  телепортации; Элитрам нужна минимальная высота/разгон для раскрытия.
- **Тотем**: работает только из хотбара (не из второй руки постоянно),
  или кулдаун 30-60 сек после срабатывания.
- **"Бессмертие" едой (combat tag)**: при получении урона регенерация от
  скрытой сытости (золотая морковь и т.п.) блокируется на несколько
  секунд.

### MLG / физика
- **Вода гасит падение только от 3+ блоков глубины** — ведро в 1 блок
  разлитой воды не спасает.
- **Гидроудар**: при падении с очень большой высоты часть урона проходит
  даже при приземлении в океан.
- **Кулдаун 1-2 сек на сбор разлитой воды обратно в ведро** — не даёт
  спамить водой без последствий (успеет смыть факелы/редстоун/посадки).
- **Каркасные блоки** в системе "клейкости": железные блоки/брёвна/
  кирпичи держат вокруг себя больше "слабых" блоков, чем камень/земля.

## Как собрать — вариант A: без IDE, из командной строки (слабый ПК)

IntelliJ на слабой машине (4 ГБ ОЗУ + HDD) — это реально боль, и по факту
она не обязательна, wrapper уже лежит в архиве.

1. Поставь JDK 17 (Temurin 17, adoptium.net) — это единственное, что нужно.
2. Открой командную строку (`cmd` или PowerShell) в папке проекта.
3. Запусти:
   ```
   gradlew.bat build --no-daemon
   ```
   `--no-daemon` — принципиально: без него Gradle оставляет процесс висеть
   в памяти после сборки и жрёт ОЗУ дальше. С флагом он завершается и
   отпускает память сразу после build.
4. Если совсем туго с памятью, можно урезать лимит в `gradle.properties`
   (строка `org.gradle.jvmargs`) с `-Xmx2G` до `-Xmx1536M` — риск чуть выше
   (может не хватить на этапе ремаппинга майна), но шанс есть.
5. **Первая сборка всё равно будет тяжёлой** — Gradle скачает и переупакует
   ванильный Minecraft (это не облегчить, разовая штука, дальше кешируется).
   На HDD это может занять по-настоящему долго и погонять диск — закрой
   всё лишнее (браузер, дискорд) на время первой сборки.
6. Готовый джарник — `build/libs/noabuse-0.1.0.jar`.

## Как собрать — вариант B: в облаке, без нагрузки на ПК вообще

Если вариант A всё равно слишком тяжёлый — в архиве уже лежит
`.github/workflows/build.yml`, который собирает мод на серверах GitHub
(бесплатно для публичных репозиториев), а тебе останется только скачать
готовый .jar.

1. Заведи аккаунт на github.com (если ещё нет).
2. Создай новый репозиторий (New repository), можно приватный или публичный.
3. На странице репозитория — "uploading an existing file", перетащи туда
   всю папку `noabuse-mod` (или все файлы из неё) и закоммить — это можно
   сделать прямо в браузере, без установки git.
4. Открой вкладку **Actions** в репозитории — сборка запустится сама
   (на пуше в main/master) через пару минут.
5. Когда сборка позеленеет — внизу страницы запуска будет **Artifacts**,
   там `noabuse-mod-jar` — скачивай, внутри уже готовый .jar.

Твой компьютер в этом варианте вообще не участвует в компиляции — только
браузер, чтобы залить файлы и скачать результат.

## Fabric API и сам Fabric

В обоих вариантах отдельно (наш мод — не замена этому, а дополнение):
скачай **Fabric Loader ≥0.14.21** через официальный установщик на
fabricmc.net (профиль 1.20.1) и **Fabric API 0.86.1+1.20.1** с modrinth.com.
Оба файла (Fabric API + наш `noabuse-0.1.0.jar`) кинь в
`%appdata%\.minecraft\mods`.

## Если не собралось

Самое рискованное место в этом черновике — имя класса `EyeOfEnderEntity` и
константа `0.2F` внутри его `tick()`: я взял их по памяти о структуре Yarn
1.20.1, но не смотрел живой декомпилированный код. Если Mixin ругнётся на
старте игры ("Constant not found" / "Unable to locate target method") —
это именно сюда. `TotemMixin` (метод `tryUseTotem`) — куда более стабильная
штука, там риск ниже.
